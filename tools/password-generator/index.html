Password Generator

Published 2026-10-07

The Password Generator creates strong random passwords in your browser, with adjustable length and character groups. It is free, needs no signup and never sends a password anywhere.

What the Password Generator lets you control

Choose a length from 8 to 64 characters and decide which groups to use: lowercase letters, uppercase letters, numbers and symbols. You can also skip look-alike characters, which helps when you must read a password aloud or type it by hand. The tool includes at least one character from every selected group and then shuffles the result, and it picks characters in an unbiased way, so no character is more likely than another. A strength label and an entropy figure in bits appear next to each password.

How we tested the Password Generator and what it cannot do

We ran the tool with its default settings and again with symbols and look-alike characters switched off, and confirmed that each result followed the chosen rules. We also made five passwords at once and checked that all of them were different. The screenshots show these runs. The strength figure is an estimate that only applies to random passwords, not to ones you invent yourself. Some websites reject certain symbols, so you may need to turn symbols off. Copying can be blocked by browser settings, and then you can select the password and copy it by hand.

Using the Password Generator the safe way

Make a new password for every account and keep it in a password manager instead of reusing one. Length matters more than complexity, so raising the length adds more strength than adding one more symbol. If a site limits the length or the symbols, change the settings rather than editing the result, because hand edits make passwords more predictable. Do not share generated passwords by email or chat. Passwords here are created in your browser and are not stored, so copy the one you want before you close the page.

Password Generator questions and answers

Is the Password Generator free to use?

Yes. It is free, needs no signup and has no limit on how many passwords you can make.

Are passwords from the Password Generator stored or sent anywhere?

No. They are created in your browser with its secure random number generator. Nothing goes to a server, and the password is gone when you close the tab.

How long should a password from the Password Generator be?

Longer is stronger. The tool offers 8 to 64 characters, and 16 is a sensible default for most accounts. A password manager makes long passwords easy to use.

What does the strength estimate in the Password Generator mean?

It shows how many guesses a random password of that length and character mix would need, measured in bits. More bits means more guesses. It does not judge passwords you invent.

Can the Password Generator skip characters that look alike?

Yes. Switch on the look-alike option and the tool leaves out characters that are easy to confuse, which helps when you type a password by hand.
