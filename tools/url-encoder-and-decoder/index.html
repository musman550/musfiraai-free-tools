URL Encoder and Decoder

Published 2026-11-01

The URL Encoder and Decoder percent-encodes or decodes text for web addresses, free with no signup.

What makes the URL Encoder and Decoder useful

This tool encodes text to fit within a web address and decodes it back, handling accents and symbols by using UTF-8. You can choose to encode either a single value or an entire URL. It reports malformed percent sequences with clear messages and runs entirely in your browser without uploading or storing any text. Decoding does not convert plus signs into spaces, and invalid percent sequences are reported rather than guessed. Each time you decode, only the first level of encoding is processed. This tool is useful for building query strings, reading encoded links, fixing links with spaces or accents, and preparing values for redirect parameters.

Reliability notes for the URL Encoder and Decoder

The URL Encoder and Decoder was rigorously tested across various real browsers at both desktop and phone screen sizes using sample inputs to ensure accurate encoding and decoding. The tool successfully handles accents, symbols, and other Unicode characters by utilizing UTF-8 encoding. When decoding, it reports malformed percent sequences with clear messages but does not convert plus signs into spaces, nor does it guess at invalid percent sequences. Only the first level of encoding is decoded each time. Known limitations include these behaviors, which users should be aware of when building a query string or fixing links containing spaces or accents.
